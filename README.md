## Featured Project

### TasteLocal

TasteLocal is a full-stack local food tourism platform designed to help visitors discover authentic Singapore food experiences while providing management tools for vendors and administrators.

### Key Features

- Tourist, Vendor, and Administrator user roles
- JWT authentication
- Role-based protected routes
- Food experience discovery
- Search and filtering
- Booking management
- Vendor experience management
- Reviews
- Food itinerary / planner
- REST API integration
- Responsive user interface
